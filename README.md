# Master Machine Learning with Python

This repository contains marimo notebooks that follow the lessons in the book "Master Machine Learning with Python" by Kevin Markham, based on his course materials and teaching flow. The exercises begin with Chapter 2 and continue through the practical machine learning topics covered in the book.

## About the book

The book is a hands-on introduction to machine learning using Python. It focuses on building a strong foundation in supervised learning, model evaluation, and real-world workflows, while helping learners move from theory to applied practice.

## Overall outline

The material in this repo follows the structure of the book and its core learning progression:

- Introduction to machine learning and the workflow
- Data preparation and exploratory analysis
- Feature engineering and preprocessing
- Model training and evaluation
- Cross-validation and model selection
- Classification and regression fundamentals
- Linear models and decision boundaries
- Tree-based models and ensemble methods
- Model interpretability and diagnostics
- Practical project workflow and deployment mindset

## Brief summary

This book teaches data science and machine learning in a practical, code-first way. It emphasizes understanding how models work, how to validate them properly, and how to make informed decisions using real datasets. The exercises in this repo mirror that approach by using Python and marimo notebooks to explore each concept interactively.

## Repository contents

- `Exercises_by_Chapter/` — notebooks and exercise scripts organized by chapter
- `Datasets/` — sample datasets used throughout the lessons
- `assets/` — styling and supporting files for the notebook experience
- `layouts/` — slide layout configuration for presentation use

## Notes

These notebooks are intended as a study companion for the book and follow the lesson progression from Chapter 2 onward, with a focus on learning by doing.
